## Bärenfinale-Qualifier
[Companion-Code](/faq/#was-hat-es-mit-dem-companion-code-auf-sich): **[XQ665D5](https://magic.wizards.com/en/products/companion-app?shortCode=XQ665D5)** \
Kosten: 20.- (Mitglieder), 25.- (Nichtmitglieder) \
Format: Pick-2-Draft (verschiedene Sets), Single-Elimination \
Startet sobald 4 Spieler bereit sind. Sieger von jedem Pod qualifiziert sich für das Bärenfinale. \
Spieler können mehrere Drafts nacheinander spielen, müssen aber für jeden Draft die Kosten bezahlen. \
Mitbringen: Kartenhüllen, etwas zum Lebenspunkte notieren; optional: Würfel, Tokens, Spielmatte

## Star Trek Draft
[Companion-Code](/faq/#was-hat-es-mit-dem-companion-code-auf-sich): **[7G55R5M](https://magic.wizards.com/en/products/companion-app?shortCode=7G55R5M)** \
Kosten: 25.- (Mitglieder), 30.- (Nichtmitglieder) \
Gespielt werden 3-4 Runden, abhängig von der Anzahl Teilnehmer. \
Pro Spieler geht ein Booster in den Preispool. \
Mitbringen: Kartenhüllen, etwas zum Lebenspunkte notieren; optional: Würfel, Tokens, Spielmatte
